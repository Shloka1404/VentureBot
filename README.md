# Venture

 **Originally built as a Hugging Face Space:** https://huggingface.co/spaces/kode-with-klossy/4.3-groupA3-capstone

## What it does

- Ask for specific scholarships
- Personalized internship opportunities for your statistics 
- Educational opportunities for minority communities
  
## How it works

Our project streamlines opportunity discovery by matching users with customized opportunities based on their unique needs, interests, and qualifications, using data from our curated database.## Built with

- **Gradio** - the interface
- **Hugging Face Inference Providers** - An AI model 

## What I learned
I learned how to create a platform, which is centered on users that matches individuals, specifically from the minority communities with relevant opportunities based on their needs and preferences. This project helped me develop skills in data organization, problem-solving, and designing personalized recommendation systems.
